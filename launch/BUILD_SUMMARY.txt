ARCHITECTURE & HOW IT WORKS
================================================================================

Execution Flow:

User clicks .exe
    ↓
launcher.py starts (Main process)
    ├─→ Validate environment
    │   ├─ Check .venv exists
    │   ├─ Check PowerShell scripts exist
    │   └─ Check Python dependencies installed
    │
    ├─→ Spawn Worker Process (new PowerShell window)
    │   └─→ start_worker.ps1
    │       ├─ Activate .venv
    │       ├─ cd to team-grade-processing
    │       └─ python -m ingest.ingest_worker
    │
    ├─→ Spawn API Process (new PowerShell window)
    │   └─→ start_api.ps1
    │       ├─ Activate .venv
    │       ├─ cd to team-grade-processing
    │       └─ python api/server.py
    │
    ├─→ Wait for API readiness (up to 30 seconds)
    │
    ├─→ Open browser to http://localhost:8000
    │
    └─→ Display status and monitor processes

Key Design Decisions:

1. Separate Processes
   - If one component crashes, others keep running
   - Easier to debug (separate logs in each window)
   - Can restart individual components independently

2. New PowerShell Windows
   - Easy to see logs for each component
   - Can interact with each process separately
   - Windows handles terminal management automatically

3. Orchestrator Process (launcher.py)
   - Coordinates startup sequence
   - Monitors all child processes
   - Displays status to user
   - Handles errors gracefully

4. venv Activation
   - Each process activates its own venv
   - No global environment pollution
   - Works in any working directory
   - No PATH modifications needed

5. ASCII-Only Logging
   - No Unicode characters (✓ ✗ ⚠) 
   - Uses [OK] [FAIL] [WARN] instead
   - Works on all Windows versions
   - No encoding errors in console

TROUBLESHOOTING
================================================================================

PROBLEM: "Virtual environment not found"
SOLUTION:
  1. Verify .venv exists: Test-Path "C:\Users\ricky\OneDrive\Desktop\Team-Grade\TEAM-GRADE\.venv"
  2. If missing, create it: python -m venv .venv
  3. Install dependencies: .\.venv\Scripts\pip install -r requirements.txt
  4. Rebuild launcher: .\build_launcher.ps1 -Clean

PROBLEM: "Failed to spawn worker" or "Failed to spawn API"
SOLUTION:
  1. Check PowerShell execution policy: Get-ExecutionPolicy
  2. If "Restricted", allow local scripts: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. Try again

PROBLEM: "API server not responding"
SOLUTION:
  1. Check if port 8000 is already in use: netstat -ano | findstr ":8000"
  2. Kill the process: taskkill /PID <pid> /F
  3. Try again
  4. Wait longer - first startup can take 30+ seconds

PROBLEM: ".exe won't run"
SOLUTION:
  1. Verify all project files exist
  2. Verify .venv is in the correct location
  3. Try running from command line to see error messages:
     C:\Users\ricky\OneDrive\Desktop\Team-Grade\TEAM-GRADE\launch\dist\TEAM-GRADE-Launcher.exe
  4. Check build_log.txt for build issues
  5. Rebuild: .\build_launcher.ps1 -Clean

PROBLEM: "Missing DLL" or "Module not found"
SOLUTION:
  1. Update dependencies: pip install -r requirements.txt  
  2. Check if yt_dlp is installed: pip install yt_dlp
  3. Rebuild launcher: .\build_launcher.ps1 -Clean
